# glyna.papir

Крамниця речей з історією та культурним сенсом: кераміка, книги, листівки, графіка.

Сайт готовий до розміщення на **GitHub Pages**.

## Як запустити на GitHub Pages

1. Створи новий репозиторій на GitHub (наприклад `glyna-papir`).
2. Завантаж усі файли з цієї папки в репозиторій.
3. Зайди в **Settings → Pages**.
4. У розділі **Source** обери гілку `main` (або `master`) і папку `/ (root)`.
5. Натисни **Save**.
6. Через кілька хвилин сайт буде доступний за адресою:
   `https://твій-нік.github.io/назва-репозиторію/`

## Структура проєкту

```
glyna-papir/
├── index.html
├── images/
│   ├── logo.png          ← логотип
│   ├── p1.jpg … p8.jpg   ← фото товарів
└── README.md
```

## Як додавати нові товари

Відкрий `index.html` і знайди масив `ITEMS`.

Приклад:

```js
{
  id: "9",
  cat: "ceramics",          // graphics | books | ceramics | cards
  title: "Керамічна ваза",
  author: "Автор",
  year: "1970-ті",
  size: "Висота 22 см",
  state: "Без тріщин",
  price: 1800,              // або null → «Ціна в Direct»
  photo: "vaza.jpg",        // файл у папці images/
  sold: false
}
```
